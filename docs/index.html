Card-support ticket triage

Which messages can a machine safely handle?

A sort code sends money to the right bank. Sortcode sends each support ticket to the right team, then scores five ways of doing it by what their mistakes would cost: a stolen card answered by an FAQ bot is a different failure from an FAQ landing on an agent's desk.

See it applied: a triage desk for a prepaid travel card, with where to look in the card platform, decline codes and reply starters, built from public information.
