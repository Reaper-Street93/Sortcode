Case study · prepaid travel-card support

A triage desk for a prepaid travel card

Modelled on Caxton's Currency Card using only public information: Caxton's published terms and fees, Thredd's Smart Client guide and code lists, and Checkout.com's response codes. Type a customer message to get the team it belongs with, where to look, and a reply to start from.

Independent project. Not affiliated with, endorsed by or built for Caxton, Thredd or Checkout.com. Built only from the public sources below, with no internal information and no customer data. The routing model was trained on BANKING77, a public dataset from a similar card app, not on Caxton's tickets.
